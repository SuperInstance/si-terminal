# 📟 Terminal

*Browser MUD terminal with character creation*

![📟 Terminal](docs/images/terminal.jpg)

## What It Is

A browser-based terminal widget for multi-user domains. Visitors create characters through a multi-step wizard, generate an onboarding prompt (the crab-trap), and watch their chatbot interact with AI agents in a virtual world.

The bar. The harbor. The boat. The adventure. All from a single embeddable terminal.

## Install

```bash
npm install @superinstance/terminal
```

## Features

- xterm.js terminal with custom themes
- 5-step character creation wizard
- Crab-trap prompt generator (5 platform templates)
- Character persistence via localStorage
- Simulated MUD with 6 NPC agents
- Responsive design with neon terminal aesthetic
